# LiveKeys sounds

SoundFont (SF2) banks downloadable from the LiveKeys iPad app. Converted from their original SFZ / SF2
releases; redistributed **non-commercially**, unchanged in sound, with credit to their authors.

| Bank | Author | License | Source |
|---|---|---|---|
| Upright Piano KW (full) | FreePats project (Gonzalo & Roberto) | CC0 1.0 | https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html |
| Splendid Grand Piano | AKAI (public domain), SFZ mapping by kinwie | Public domain | https://github.com/sfzinstruments/SplendidGrandPiano |
| jRhodes Mark I (light, looped) — jRhodes3c | Jeff Learman | CC BY-NC-SA 4.0 | https://github.com/sfzinstruments/jlearman.jRhodes3c |
| jRhodes Mark I (full) — jRhodes3d | Jeff Learman | CC BY-NC 4.0 | https://github.com/sfzinstruments/jlearman.jRhodes3d |

The jRhodes samples may not be used commercially; contact their author for a commercial license.
Original license and readme files are in [`licenses/`](licenses).

Files are attached to the [v1 release](../../releases/tag/v1); `catalog.json` lists them with size and SHA-256.
